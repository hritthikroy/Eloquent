## 💻 **USE ON OTHER LAPTOP:**

### Step 1: Clone Repository
```bash
git clone https://github.com/hritthikroy/Eloquent.git
cd Eloquent/EloquentElectron
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Configure Environment
```bash
cp .env.example .env
nano .env  # Add your Groq API key
```

### Step 4: Run!
```bash
npm start
```
