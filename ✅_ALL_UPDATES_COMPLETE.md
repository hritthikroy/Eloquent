## 💻 **CLONE ON ANY LAPTOP:**

### Quick Setup (2 Minutes):
```bash
# 1. Clone
git clone https://github.com/hritthikroy/Eloquent.git
cd Eloquent/EloquentElectron

# 2. Install
npm install

# 3. Configure
cp .env.example .env
nano .env  # Add: GROQ_API_KEY=your_key_here

# 4. Run!
npm start
```

### Platform-Specific:

