## 💻 **USE ON ANY LAPTOP (2 MINUTES):**

### Step 1: Clone
```bash
git clone https://github.com/hritthikroy/Eloquent.git
cd Eloquent/EloquentElectron
```

### Step 2: Install
```bash
npm install
```

### Step 3: Configure
```bash
cp .env.example .env
nano .env  # Add: GROQ_API_KEY=your_key_here
```

### Step 4: Run
```bash
npm start
```

**Done! ⚡**

## 🚀 **HOW TO USE:**

### Standard Voice-to-Text:
```
1. Press Alt+Space
2. Speak clearly
3. Press Esc
4. Text appears! ✨
```

### AI-Enhanced Mode:
```
1. Press Alt+Shift+Space
2. Speak naturally (don't worry about grammar)
3. Press Esc
4. AI-enhanced text appears! 🤖✨
```

**Example:**
- **You say:** "um like so basically I was thinking that maybe we could uh you know try this"
- **AI outputs:** "I was thinking we could try this."
